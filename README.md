The assignment involves estimating the unknown parameters θ, M and X in a given parametric equation of a curve. 
The parameters have specified ranges and t ranges from 6 to 60. 
The objective is to obtain parameters for which the generated curve closely matches the expected curve, with L1 distance used as the evaluation criterion.
I approached the problem computationally by defining the parametric equations, generating points over the given t range and searching for parameter values that minimize the error.

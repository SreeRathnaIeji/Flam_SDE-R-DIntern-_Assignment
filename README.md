Curve Parameter Estimation

The assignment involves estimating the unknown parameters θ, M and X in a given parametric equation of a curve. The parameters have specified ranges and t ranges from 6 to 60.

I first implemented the given parametric equation in Python and generated points for different values of t. The next step would be to compare the generated curve with the provided curve data and search for the parameter values that give the minimum L1 error.

The assignment refers to an `xy_data.csv` file containing the curve points, which is required for completing the parameter estimation. Since that data file was not included with the assignment PDF I received, the current code demonstrates the curve generation part.
